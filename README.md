# 移动端语言听写练习工具（sologsb-1029）

面向手机使用的听写练习应用，包含学习端和教师反馈视图。课程、未提交答案、练习进度、逐词结果与反馈均保存在浏览器本地，可离线继续已下载课程。

## 功能

- 课程库：按课程和课节展示难度、句数、预计时长与下载状态。
- 离线课程：可切换课节下载标记；首次访问后由 Service Worker 缓存应用壳，断网重开仍可进入已下载课程并继续编辑。
- 听写流程：调用浏览器语音合成播放完整句子，输入答案后按句导航或整课提交。
- 逐词判错：使用词级序列比对识别拼写、漏词和多余词，并生成单句与整课得分。
- 错误复核：错误词可单独重听；可选择起止词重听指定片段；可为每个错误选择类别并记录原因。
- 教师反馈：教师视图可选择学生作答并写入反馈，反馈会回显在学习记录中。
- 共享练习会话：作答、提交、反馈、错误分类都带来源（标签/角色）与全局递增序号追加写入本机操作账本；保存前核对同一课节版本，发现别的标签已改时保留双方草稿并列出冲突，逐项确认合并（保留本地/采用他处）后才提交。
- 幂等与重放：同一操作或同一提交重复执行只生效一次；标签重新显示或断网恢复时按账本合并重放；本机容量不足时拒绝写入并保留原记录与草稿，可重试。
- 旧数据迁移：v1 整体存档首次打开自动迁移为账本操作；迁移或重放失败时恢复/保留原内容并提供重试入口。
- 进度恢复：保存每句答案和当前句，刷新、切换应用或手机旋转后可恢复。
- 可访问性：支持浅色/深色模式、五档字号区间、触控尺寸、键盘提交和减少动态效果偏好。
- 记录导出：将练习历史、逐词结果、错误分类、原因和教师反馈导出为 JSON。

## 技术栈

- Vue 3
- TypeScript 5
- Varlet UI
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器监听 `0.0.0.0`，适合通过局域网在手机浏览器中测试。宿主机正式端口按根目录 `docker-compose.yml` 映射为 `10029:80`。

## 类型检查、生产构建与会话逻辑验证

```bash
npm run typecheck
npm run build
npm run test:session
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1029 .
docker run --rm -p 10029:80 sologsb-1029
```

最终镜像仅包含 nginx 和静态构建产物，nginx 监听容器 `80`。

## 数据说明

数据为本地优先（localStorage），由三类键组成（v2 账本结构）：

- `sologsb-1029-ledger-v2`：只追加的操作账本。每条操作带 `source`（标签 id、角色、展示名）与全局递增 `seq`，类型包括 `answer`（逐句作答）、`submit`（整课提交+逐词结果快照，带幂等键）、`feedback`（教师反馈）、`classify`（错误分类/原因）。课程进度、逐词结果、教师反馈与导出均读取账本重放后的合并结果。
- `sologsb-1029-prefs-v2`：主题、字号、角色、下载标记等偏好。
- `sologsb-1029-drafts-v2:<tabId>`：当前标签尚未入账的草稿（含未入账提交快照），冲突确认或断网恢复后合并。

写入流程为「合并磁盘账本 → 重放取最新课节版本 → 字段级核对 → 追加并连续编号 → 原子写盘」。容量不足先以增量探针预检，失败时原键内容不变。旧键 `sologsb-1029-dictation-state-v1` 首次打开时自动迁移，迁移期间保留备份，失败可重试。导出文件为 UTF-8 JSON，包含合并后的练习历史、逐词结果、错误分类、原因、教师反馈与账本序号。
